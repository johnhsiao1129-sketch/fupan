🔥 标的热度 - 使用说明 ×

一、功能介绍

标的热度板块展示市场中创新高和成交额领先的股票，帮助您捕捉市场热点和资金流向。

二、数据源说明

1. 新高榜（含子选项卡）
  • 半年新高：过去半年内创出新高的股票
  • 一年新高：过去一年内创出新高的股票
  • 历史新高：上市以来创出历史新高的股票
  • 板块新高数(全部)：统计各个行业的半年新高、一年新高、历史新高股票数量
  • 板块新高数(历史)：统计各个行业的历史新高股票数量
2. 成交额榜
  • 竞价成交额：每日9:25竞价时前20名成交额股票
  • 全天成交额：每日15:00收盘后前20名成交额股票

三、交互功能

1. 鼠标悬停提示（板块新高数）

在"板块新高数"选项卡中，鼠标悬停在行业名称上时，会显示该行业创新高的股票列表，包含股票名称、代码和涨幅。

2. 日期选择器

点击日期输入框可选择查看历史交易日数据，支持从弹窗中选择日期。

3. 数据刷新

点击刷新按钮（🔄）可重新获取当前日期的数据。

四、刷新规则

1. 数据刷新时机
  • 竞价成交额：每日9:25后可更新
  • 全天成交额：每日15:00后可更新
  • 新高榜：仅支持刷新交易日数据，刷新历史日期不会更新新高数据
2. 竞价成交额的特殊规则

竞价数据当日录入后不可再修改，确保数据的真实性和一致性。

五、常见问题及解决方法

1. 新高榜股票数量不对

问题1：自己刷新时显示3只新高，但再次查询时显示19-20只。
原因1：AkShare的"新高榜"数据是实时变化的。在市场交易期间，股票价格会持续波动，创新高的股票数量会不断增加。
问题2：刷新往期日期后，新高数量没有变化。
原因2：新高接口无日期参数，只能获取最新数据。系统会自动拦截往期日期的新高数据刷新。
解决办法：

  • 建议在市场收盘后（15:00以后）刷新数据，确保数据稳定
  • 刷新往期日期时，新高数据不会被更新（仅更新涨停/跌停等有日期参数的接口）
  • 如需实时数据，可在交易时段稍后再次刷新
  • 每次刷新时的数量差异是正常现象，非程序bug

2. 数据无法刷新

问题：点击刷新按钮后提示需要等待。
原因：根据不同数据源的规则，需要在特定时间后才能更新。
解决办法：

  • 全天成交额：需等待15:00市场收盘后
  • 历史日期：无时间限制，随时可更新涨停/跌停数据
  • 新高数据：只能刷新交易日，刷新历史日期会自动跳过

2. 数据无法刷新

问题：点击刷新按钮后提示需要等待。
原因：根据不同数据源的规则，需要在特定时间后才能更新。
解决办法：

  • 全天成交额：需等待15:00市场收盘后
  • 历史日期：无时间限制，随时可更新涨停/跌停数据
  • 新高数据：只能刷新交易日，历史日期会自动跳过（接口无日期参数）

3. 新高数据刷新限制

重要：新高数据（历史新高、一年新高、半年新高）接口
不支持日期参数，只能获取最新数据。

  • 刷新最新交易日：正常获取并保存新高数据
  • 刷新往期日期：只刷新涨停/跌停数据，不刷新新高数据
  • 系统会自动检测交易日，阻止刷新往期日期的新高数据

🎯 连板梯队 - 使用说明 ×

一、功能介绍

连板梯队展示市场中连续涨停的股票，按照连板天数进行分组分类，帮助您直观了解当前市场的接力情况和市场热度。

二、数据说明

1. 连板分组

将所有连续涨停的股票按照连板天数分组，从10板开始降序排列，依次为10板、9板、8板...2板。

  • 10板：连续10个交易日涨停
  • 9板：连续9个交易日涨停
  • ...：以此类推
  • 2板：连续2个交易日涨停
2. 股票信息

每个连板分组中展示该天数的所有股票，每只股票显示以下信息：

  • 股票代码：6位数字代码（如：600397）
  • 股票名称：股票简称（如：江钨装备）
  • 涨停价格：最新成交价格
  • 涨停时间：首次涨停时间（时间格式如：09:25:00）
  • 所属板块：股票所属行业或概念
  • 涨停原因：涨停的主要原因（如有）
3. 连板总数统计

在标题旁显示一个数字标签（如：23），表示当前市场所有2板及以上连板股票的总数量。

三、交互功能

1. 滚动查看

当连板股票数量较多时，列表支持滚动查看，最大高度为400像素。

2. 数据刷新

点击刷新按钮（🔄）可重新获取当前日期的连板数据。

3. 连板分析编辑

在底部提供连板分析文本框，可记录对当天连板梯队的观察和总结，支持失焦自动保存。

四、判断规则

1. 连板判定标准
  • 连续性：必须连续多个交易日涨停，中间不能有跌停或未涨停的交易日
  • 最低要求：至少连续2个交易日涨停（2板及以上显示，首板不在此展示）
  • 数据来源：基于实际交易数据计算，确保准确性
2. 特殊情况处理
  • T字板：算作涨停，计入连板天数
  • 一字板：算作涨停，计入连板天数
  • 炸板：当天未封板，中断连板（计入炸板数据，不在连板梯队显示）
  • 跌停：中断连板

五、使用技巧

1. 市场热度判断

高连板数量多：说明市场接力情绪强，风险偏好高
高连板数量少：说明监管严或市场情绪谨慎，注意风险

2. 关注龙头

高连板（5板以上）的股票通常是市场龙头或核心题材，值得重点关注。注意其题材属性和涨停时间（早盘封板更有力）。

3. 板块联动

观察同一板块是否有多个连板股票，判断板块持续性。板块内连板股票越多，说明板块越强势，持续性越好。

4. 连板分析建议

在分析文本框中记录以下信息，帮助复盘：

  • 最高连板多少板？龙头是谁？
  • 哪些板块有多只连板？
  • 连板数量与昨日对比是增加还是减少？
  • 涨停时间分布如何？（早盘/午盘/尾盘）
  • 是否有值得关注的异动连板股？

六、常见问题

1. 暂无连板数据

问题：显示"暂无连板数据"
原因：当日市场没有连续2天及以上涨停的股票，或者数据尚未更新
解决办法：点击刷新按钮重新获取数据，或等待数据更新

2. 连板数量与实际不符

问题：显示的连板数量与盘中看到的不一致
原因：系统使用历史交易数据，盘中数据可能因股票炸板、开板等实时变化
解决办法：建议在市场收盘后（15:00）刷新查看，数据更准确

🆕 今日首板 - 使用说明 ×

一、功能介绍

今日首板展示当天首次涨停的股票，支持按题材分类整理，帮助您快速了解当日市场的新热点和资金流向。

二、数据说明

1. 首板定义
  • 首次涨停：当日首次涨停的股票（不包括连续涨停的股票）
  • 统计口径：严格区分首板和连板，连板股票不在此列表中
  • 数据来源：通过API实时获取涨停数据，确保准确性
2. 股票信息

每只首板股票显示以下信息：

  • 股票名称：股票简称（如：江钨装备）
  • 涨跌幅：涨停时的涨幅显示为+10.00%（或其他涨停幅度）
  • 涨停时间：首次涨停的时间（时间格式如：09:30:00）
  • 所属板块：股票所属行业或概念
3. 题材分类

首板股票可以按题材进行分类整理，每个题材卡片显示该题材下的所有首板股票。

三、交互功能

1. 添加/删除题材

点击"＋ 添加题材"按钮，可以在弹窗中创建新题材或选择已有题材，然后将股票拖入题材卡片中。

2. 拖拽分类

支持将首板股票拖拽到不同题材卡片中进行分类整理。鼠标左键按住股票卡片，拖动到目标题材上方释放即可。

3. 从题材删除

点击题材卡片中的股票删除按钮（×），可以选择仅从今日首板删除，或同时删除题材属性。

4. 股票筛选

在搜索框中输入股票名称的拼音首字母或股票代码，可快速筛选股票。

  • 拼音首字母：例如输入"JW"查找"江钨"
  • 股票代码：例如输入"600397"
  • 支持模糊匹配
5. 折叠列表

点击"全部首板标的"右侧的▼图标，可以折叠或展开首板列表，节省显示空间。

6. 日期选择

点击日期输入框可选择查看历史交易日的首板数据，支持从弹窗中选择日期。

四、操作流程

典型使用流程
  1. 查看当日首板股票列表，了解市场热点
  2. 点击"＋ 添加题材"创建或选择题材（如"人工智能"、"新能源"等）
  3. 将相关股票拖拽到对应题材卡片中
  4. 使用搜索框快速定位特定股票
  5. 切换查看历史交易日的数据

五、使用技巧

1. 捕捉市场热点

快速涨停：早盘封板的首板股票值得关注，可能成为当日热点
题材集中：同一题材有多只首板，说明该题材受资金追捧
涨停时间：记录涨停时间，分析市场情绪变化

2. 题材持续性判断

观察题材：首板股票集中在哪些题材，判断当日主线
比较题材：不同题材的首板数量对比，判断资金流向
跟踪演变：历史数据对比，看题材持续性

3. 分类整理建议
  • 按题材分类：如"人工智能"、"新能源汽车"、"半导体"等
  • 按属性分类：如"核心标的"、"跟风标的"、"妖股"等
  • 按板块分类：如"科技板块"、"医药板块"、"军工板块"等

六、常见问题

1. 显示"今日暂无首板数据"

问题：显示"今日暂无首板数据"
原因：当日市场没有首次涨停的股票，或数据尚未更新
解决办法：点击日期选择器查看其他日期的数据，或等待数据更新

2. 拖拽股票到题材无反应

问题：拖拽股票到题材卡片后，股票没有进入该题材
原因：可能拖拽位置不对，或题材卡片区域识别不准确
解决办法：确保拖拽到题材卡片区域内，释放鼠标前看到高亮提示

3. 拼音搜索不匹配

问题：输入拼音首字母找不到股票
原因：输入的拼音首字母不正确，或该股票的拼音映射未包含在字典中
解决办法：尝试输入正确的拼音首字母，或直接使用股票代码搜索

4. 删除题材与删除今日首板的区别

删除今日首板：仅将该股票从今日首板的题材关联中删除，不影响题材属性
删除题材：将该股票从题材属性中完全删除，需要检查是否还有其他关联记录
建议：一般情况下选择"仅删除今日首板"，除非确定要取消该股票的题材属性

📈 涨跌停统计 - 使用说明 ×

一、功能介绍

涨跌停统计展示当日市场涨停、跌停、炸板等数据，帮助您快速了解市场整体情绪和热度情况。

通过对比历史数据的中位数和前一日的变化，可以判断当前市场情绪是高于还是低于正常水平。

二、数据说明

1. 首板（首次涨停）
  • 定义：当日首次涨停的股票数量
  • 变化值：与前一日相比的变化数量
  • 历史中位数：过去10个交易日的中位数，用于判断当前水平
  • 筛选：点击首板卡片，可筛选出首板股票
2. 连板（连续涨停）
  • 定义：连续2个及以上交易日涨停的股票数量
  • 变化值：与前一日相比的变化数量
  • 历史中位数：过去10个交易日的中位数
  • 筛选：点击连板卡片，可筛选出连板股票
  • 说明：不包括首板股票，只统计真正的连板（2板及以上）
3. 炸板（涨停打开）
  • 定义：当日涨停后打开、未封板的股票数量
  • 炸板率：炸板数量 ÷（炸板数+封板数）×100%
  • 变化值：与前一日相比的变化数量
  • 历史中位数：过去10个交易日的中位数
  • 筛选：点击炸板卡片，可筛选出炸板股票
  • 含义：炸板率高说明封板意愿弱，市场情绪谨慎
4. 跌停（跌停板）
  • 定义：当日跌停的股票数量
  • 变化值：与前一日相比的变化数量
  • 历史中位数：过去10个交易日的中位数
  • 筛选：点击跌停卡片，可筛选出跌停股票
  • 含义：跌停数量多说明市场风险偏好低，恐慌情绪重

三、市场情绪指标

情绪等级

右上角显示当日市场情绪等级，共5个级别：

  • 低迷（灰色）：市场情绪极度消极，首板数量少，跌停多
  • 谨慎（浅红色）：市场情绪偏谨慎，但有一定热度
  • 正常（绿色）：市场情绪正常，处于健康水平
  • 活跃（深红色）：市场情绪活跃，涨停数量多
  • 狂热（紫色）：市场情绪极度亢奋，涨停数量爆发
情绪计算逻辑

基于首板、连板、炸板、跌停的数量综合计算，考虑历史平均水平。

四、交互功能

1. 日期选择

点击日期输入框，在弹出日历中选择历史交易日，查看该日期的涨跌停数据。

2. 回到今日

点击"↺"按钮，快速返回到今日的数据视图。

3. 数据筛选

点击任意数据卡片（首板/连板/炸板/跌停），可以在下方的详细列表中筛选出对应的股票。

4. 涨跌幅颜色
  • 红色：代表数据增加（如首板数量增加）或涨幅为正
  • 绿色：代表数据减少（如首板数量减少）或跌幅为负
5. 数据来源

标题显示数据来源（如"【麦瑞数据】"、"【东方财富】"）和展示日期，了解数据来源的可靠性。

五、使用技巧

1. 判断市场热度

首板数量：首板数量越多，市场热度越高，题材扩散越广
连板数量：连板数量多，说明接力情绪强，市场赚钱效应好
炸板率：炸板率低（<30%）说明封板意愿强，情绪好；炸板率高（>50%）说明情绪谨慎

2. 对比历史水平

高于中位数：当前市场热度高于历史平均水平，情绪积极
低于中位数：当前市场热度低于历史平均水平，情绪消极
变化趋势：观察连续几日的方向，判断情绪是上升还是下降

3. 捕捉拐点信号

情绪回升：首板数量持续增加，从低于中位数转为高于中位数
情绪降温：炸板率持续上升，首板数量减少
极端信号：首板>50只（过热），或首板<5只（过冷）

4. 综合分析
  • 首板+连板都高：市场全面走强，机会多
  • 首板高、连板低：新题材爆发，但接力不足，观察持续性
  • 首板低、连板高：存量博弈，新题材少，注意风险
  • 跌停数量增加：市场风险加大，谨慎操作
  • 炸板率暴增：市场分歧加大，情绪转冷

六、常见问题

1. 数据与实际不符

问题：显示的数量与盘中看到的不一致
原因：数据是盘中或收盘后的固定时间点数据，盘中数据会实时变化
解决办法：建议在收盘后（15:00）查看，数据更稳定准确

2. 历史中位数不准

问题：中位数与经验值有差异
原因：中位数基于过去10个交易日计算，不同时期市场环境不同
建议：中位数是动态变化的，应该关注相对位置而非绝对值

3. 情绪等级不合理

问题：情绪等级与主观感受不一致
原因：情绪等级基于量化指标，可能忽略了一些定性因素
解决办法：情绪等级作为参考，结合实际盘面和市场环境综合判断

4. 如何根据数据调整策略

情绪活跃（活跃/狂热）：可以积极出击，参与强势题材和龙头股
情绪正常（正常）：保持正常节奏，精选个股，控制仓位
情绪低迷（低迷/谨慎）：谨慎操作，降低仓位，观望为主

5. 涨跌幅颜色显示

注意：涨跌幅颜色采用A股惯例，红色代表上涨，绿色代表下跌
变化值颜色：数量增加显示为红色（正向变化），减少显示为绿色（负向变化）

🔄 题材轮动分析 - 使用说明 ×

一、功能介绍

题材轮动分析展示各题材在不同日期的活跃情况，帮助您追踪市场热点的演变规律，发现题材的启动、爆发、维持、衰退等生命周期阶段。

二、界面布局

1. 日期导航栏

顶部显示多个交易日的日期，用于横向切换查看不同日期的题材活跃情况。

  • 滚动浏览：日期栏支持左右滚动，可查看更多历史日期
  • 添加题材：点击日期后的"+"按钮，为该日期添加题材活跃记录
  • 日期显示：显示格式为"02-10"、"02-11"等，便于快速识别
2. 题材列表

左侧显示所有已创建的题材，按首板股票数量排序，方便快速找到活跃题材。

3. 活跃状态矩阵

中间区域是主要内容，以矩阵形式展示各题材在不同日期的活跃情况：

  • 行：每个题材一行
  • 列：每个交易日一列
  • 单元格：显示该题材在该日期的活跃状态和内容

三、题材阶段说明

阶段定义
  • 爆发（红色）：题材新启动，出现大量首板股票，市场关注度急剧上升
  • 启动（橙色）：题材开始活跃，出现少量首板股票，市场开始关注
  • 维持（绿色）：题材持续活跃，首板数量稳定，市场关注度保持
  • 衰退（灰色）：题材热度下降，首板数量减少或消失
阶段筛选

点击标题下方的阶段筛选下拉菜单，可以只显示特定阶段的题材：

  • 全部：显示所有阶段的题材
  • 爆发：仅显示爆发阶段的题材
  • 启动：仅显示启动阶段的题材
  • 维持：仅显示维持阶段的题材

四、交互功能

1. 添加题材活跃记录

点击日期后的"+"按钮，在弹窗中选择或创建题材，记录该题材的活跃情况。

2. 查看题材详情

点击题材单元格可查看该题材在该日期的详细内容，包括活跃股票列表、分析总结等。

3. 编辑题材阶段

点击题材单元格中的阶段标签，可以快速切换题材的阶段状态。

4. 删除活跃记录

点击题材单元格中的"×"按钮，可以删除该题材在该日期的活跃记录。

  • 删除仅会影响该日期的记录，不会删除题材本身
  • 其他日期的题材记录不受影响
5. 滚动同步

日期栏和内容区支持同步滚动，方便对齐查看不同日期的数据。

6. 双向滚动

内容区支持横向和纵向滚动，可查看更多日期和题材。

五、使用技巧

1. 发现启动信号

观察启动阶段：题材从"启动"变为"爆发"时，是加速上涨信号
关注首板数量：启动阶段首板数量持续增加，说明题材开始发酵
时间窗口：题材启动后1-3天是最佳介入时机

2. 判断持续性

阶段演变：观察题材从启动→爆发→维持的演变过程
持续性判断：能维持多天在"维持"阶段的题材，持续性较好
警惕衰退：从"维持"进入"衰退"阶段，应及时撤退

3. 追踪轮动规律

横向对比：查看不同题材在相同时期的活跃情况，发现轮动规律
纵向对比：查看同一题材在不同日期的演变，追踪生命周期
题材接力：新题材爆发时，旧题材可能衰退，形成接力效应

4. 阶段筛选应用

抓强势：筛选"爆发"阶段，找到当前市场最强势的题材
找机会：筛选"启动"阶段，发现可能爆发的新题材
避风险：筛选"衰退"阶段，避开热度下降的题材

六、常见问题

1. 题材显示不完整

问题：部分题材没有显示在列表中
原因：该题材没有首板股票关联，或被阶段筛选过滤
解决办法：检查该题材是否有首板股票，或更改阶段筛选为"全部"

2. 阶段判断不准确

问题：题材的阶段标签与实际情况不符
原因：阶段标签是手动设置的，可能需要调整
解决办法：点击阶段标签，根据实际情况手动调整题材阶段

3. 日期栏滚动不流畅

问题：日期栏和内容区不同步
原因：JavaScript同步滚动功能出现问题
解决办法：刷新页面重试，或检查浏览器控制台错误日志

4. 如何判断题材是否值得参与

爆发阶段：首板数量多（≥5只），涨停时间早，可积极关注
启动阶段：首板数量适中（2-4只），观察能否持续
维持阶段：首板数量稳定（1-2只），可少量参与或观望
衰退阶段：首板数量减少或消失，谨慎参与或回避
