# A股复盘工具

专业的A股股票复盘分析系统，实时获取市场数据，提供全面的市场分析。

## 功能特点

- ✅ **实时数据获取** - 自动获取A股实时行情数据
- ✅ **深色主题** - 专业看盘体验，保护视力
- ✅ **紧凑布局** - 高信息密度，一屏看全所有数据
- ✅ **全面分析** - 涨跌停、连板、题材、热度多维度分析

## 核心功能

### 1. 涨跌停统计与分析
- 首板、连板、炸板、跌停数量实时统计
- 与前日对比，了解市场变化
- 近10日中位值参考
- 市场情绪阶段判断（狂热/活跃/正常/谨慎/低迷）
- 30日历史柱状图 + 中位值曲线
- 可编辑的分析说明

### 2. 连板标的与梯队解析
- 2板、3板、4板及高度连板全量展示
- 标的名称、涨停原因、价格、涨幅
- 题材组成分析
- 断板标的表现分析
- 市场高度标杆识别

### 3. 每日题材分析
- 热门题材排名
- 各题材今日涨停标的
- 题材连续表现天数统计
- 题材轮动周期分析
- 近5日题材数据展示

### 4. 标的热度分析
- 人气排名TOP10
- 成交额排名靠前标的
- 涨跌幅最大题材
- 各标的所属题材及热门原因
- 辨识度高的参考标的

### 5. 今日首板展示
- 按题材分类展示
- 按首次涨停时间排序
- 可查看历史首板（昨日、本周）
- 完整的首板原因和题材信息

### 6. 市场整体状态总结
- 全文字总结
- 可编辑修改
- 实时保存

## 快速开始

### Windows
双击 `run.bat` 即可自动安装依赖并启动服务

### Linux/Mac
```bash
chmod +x run.sh
./run.sh
```

### 手动启动
```bash
# 安装依赖
pip install -r requirements.txt

# 启动服务
python start.py
```

## 访问地址

启动后访问: [http://localhost:8000](http://localhost:8000)

## 技术栈

### 后端
- **FastAPI** - 高性能异步Web框架
- **aiohttp** - 异步HTTP客户端
- **Pydantic** - 数据验证

### 前端
- **原生JavaScript** - 无框架依赖
- **Chart.js** - 数据可视化
- **CSS Grid** - 现代化布局

### 数据源
- 新浪财经
- 东方财富网
- 腾讯财经

## 配置说明

默认配置：
- 服务端口: 8000
- 自动刷新: 5秒
- 历史数据: 30天
- 中位值计算: 最近10天

## 注意事项

- 数据更新频率：实时
- 请遵守各数据源的访问频率限制
- 建议在交易时间内使用
- 市场波动较大，注意事项仅供参考

## 开发说明

### 添加新的数据源
编辑 `src/data_client.py`，添加新的数据获取方法

### 自定义分析逻辑
编辑 `src/main.py` 中的相应分析函数

### 修改前端样式
编辑 `templates/dashboard.html` 中的CSS样式
