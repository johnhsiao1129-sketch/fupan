# 项目规则目录

本目录包含项目开发过程中积累的各种规则和最佳实践，用于避免重复犯错和提高开发效率。

## 规则文件列表

### frontend-development.md
前端开发规则，包括：
- CSS 开发规范
- 常见错误和教训
- 代码检查清单
- 调试技巧
- 工具推荐

## 使用说明

1. **在开发前阅读相关规则**：开始新功能开发前，先阅读相关的规则文件
2. **提交代码前检查清单**：使用规则文件中的检查清单进行自我审查
3. **遇到问题时查阅**：遇到问题时，先查看规则文件中是否有相关经验教训
4. **持续更新**：遇到新问题时，将教训补充到相应的规则文件中

## 添加新规则

当遇到值得记录的问题或经验时：
1. 在 `frontend-development.md` 或相应的规则文件中添加新章节
2. 描述问题现象、根本原因、解决方案
3. 提供代码示例（错误代码和正确代码）
4. 更新检查清单
